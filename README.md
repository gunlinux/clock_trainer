# Тренажёры для детей

Две независимые страницы без сборки, зависимостей и интернета — просто откройте файл в браузере. Обе рассчитаны на детей и полностью на русском языке. Рядом лежит отдельный сервер на Rust для аккаунтов и статистики; игры работают и без него.

| Страница | Что тренирует |
| --- | --- |
| `index.html` | Чтение времени по аналоговым часам — «Учимся читать время» |
| `counter.html` | Устный счёт в пределах 10 — «Учимся считать» |

## Как открыть

Скачайте папку и откройте `index.html` двойным щелчком. Либо запустите локальный сервер, чтобы избежать особенностей `file://`:

```bash
python3 -m http.server 8000
```

Затем откройте:

- часы — <http://localhost:8000/>
- счёт — <http://localhost:8000/counter.html>

Сборка, установка пакетов и подключение к сети не нужны.

В шапке обеих страниц есть кнопка **Войти**. Аккаунт необязателен: без него игры работают как раньше, а с ним каждый проверенный ответ отправляется на сервер, и в том же окне можно посмотреть личную статистику. Вход — по имени и PIN из четырёх цифр.

## Часы: «Учимся читать время»

Три режима переключаются вкладками:

1. **Выбери время** — на часах показывается время, нужно выбрать правильный вариант из четырёх. Три уровня сложности:
   - «Легко» — на циферблате подписаны минуты (5–60), время кратно 5;
   - «Средне» — подписей нет, время кратно 5, три сердечка;
   - «Сложно» — любая минута, два сердечка, варианты записаны только в 24-часовом виде.
2. **Запиши время** — время нужно ввести цифрами. Уровни те же, что в первом режиме. На «Сложно» ответ должен совпадать с точностью до минуты. Принимаются оба чтения: например, `13:45` и `01:45` — это одно и то же положение стрелок.
3. **Поставь время** — нужно выставить стрелки под объявленное время. Стрелки можно крутить кнопками или тянуть мышью/пальцем. На «Легко/Средне» минуты шагают по 5, на «Сложно» — по 1. На «Легко» цифровое табло показывает выставляемое время; на остальных уровнях оно скрыто, но проверка работает.

Особенности:

- время и его «двойник» через 12 часов считаются одним и тем же заданием, поэтому принимаются оба варианта;
- на «Средне» и «Сложно» есть сердечки: серия ошибок снимает балл, правильный ответ возвращает все сердечки;
- балл начисляется только за правильный ответ и никогда не уходит ниже нуля;
- после ответа результат и кнопка **Дальше** остаются на экране — следующее задание начинается только по нажатию;
- кнопка **Сброс** обнуляет счёт и выдаёт новое задание;
- кнопка **Помощь** открывает памятку с картинкой на весь экран; закрывается щелчком в любом месте или клавишей `Esc`.

## Счёт: «Учимся считать»

Страница `counter.html` — отдельная игра, не связанная с часами. У неё три уровня сложности:

- **Легко** — примеры с ответом от 0 до 10, ответ выбирается одной из четырёх крупных кнопок.
- **Средне** — примеры с ответом от 11 до 20, тоже четыре кнопки; примеры вроде `3 + 3` сюда не попадают.
- **Сложно** — примеры с ответом от 0 до 20, вариантов нет: число вводится в поле и отправляется кнопкой **Проверить** или клавишей `Enter`.

Правильный вариант всегда один. За верный ответ начисляется балл; при ошибке подсвечивается верный вариант и показывается равенство целиком. На «Сложно» неверный ввод показывает правильный ответ и полное равенство. После любого проверенного ответа сообщение и кнопка **Дальше** остаются на экране до нажатия — без таймеров и автоперехода.

На «Средне» три сердца, на «Сложно» два, на «Легко» сердец нет. Ошибка сжигает одно сердце; когда сгорят все, счёт уменьшается на один (но не ниже нуля), а верный ответ возвращает все сердца.

Клавиши `1`–`4` выбирают вариант на «Легко» и «Средне», `Enter` отправляет введённое число или переходит к следующему примеру. **Сброс** обнуляет счёт. В рамках одной загрузки страницы примеры не повторяются, а выбранный уровень после перезагрузки не сохраняется.

## Сервер: аккаунты и статистика

В каталоге `backend/` — служба на Rust (Axum + SQLite) для регистрации по имени и четырёхзначному PIN, сессий и статистики ответов. Страницы и API отдаются через nginx на отдельном хосте <https://clock.gunlinux.ru/>: игры — в корне (`/`, `/counter.html`), API — по адресу <https://clock.gunlinux.ru/api/>. Локально служба слушает только `127.0.0.1:6021`.

```bash
curl https://clock.gunlinux.ru/api/health
sudo systemctl status clock-trainer-api
```

Сборка, переменные окружения, схема базы, все эндпоинты и примеры запросов описаны в [`backend/README.md`](backend/README.md). Страницы подключаются к API через общие `account.js` и `account.css`: кнопка **Войти** открывает вход, регистрацию и статистику, а ответы часов и счёта уходят на сервер автоматически. В «Поставь время» сохраняются только успешные попытки — промежуточные положения стрелок ответом не считаются.

## Состав репозитория

```
index.html      разметка тренажёра часов
app.js          логика часов: циферблат, задания, проверка, счёт, режимы, помощь
styles.css      стили тренажёра часов
clock_help.png  картинка-памятка для кнопки «Помощь»
counter.html    самостоятельная игра «Учимся считать» (разметка, стили и скрипт внутри файла)
account.js      общий модуль аккаунта: вход, регистрация, отправка ответов и статистика
account.css     стили окна аккаунта и кнопки «Войти»
backend/        сервер на Rust: аккаунты, сессии, ответы и статистика (SQLite)
openspec/       спецификации обеих игр
```

`counter.html` не использует `app.js` и `styles.css`: это отдельный продукт, который можно менять, не задевая часы.

## Проверка изменений

Автоматических тестов нет. Любое изменение проверяется вручную в настоящем браузере: открыть страницу, пройти режимы, посмотреть консоль на ошибки. Для часов удобно проверить все три вкладки и все три уровня, а для счёта — все три уровня, верный и неверный ответ, ввод на «Сложно», «Дальше» и «Сброс».
