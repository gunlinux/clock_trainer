# Тренажёры для детей

Две независимые страницы без сборки, зависимостей и интернета — просто откройте файл в браузере. Обе рассчитаны на детей и полностью на русском языке.

| Страница | Что тренирует |
| --- | --- |
| `index.html` | Чтение времени по аналоговым часам — «Учимся читать время» |
| `counter.html` | Устный счёт в пределах 10 — «Учимся считать» |

## Как открыть

Скачайте папку и откройте `index.html` двойным щелчком. Либо запустите локальный сервер, чтобы избежать особенностей `file://`:

```bash
python3 -m http.server 8000
```

Затем откройте:

- часы — <http://localhost:8000/>
- счёт — <http://localhost:8000/counter.html>

Сборка, установка пакетов и подключение к сети не нужны.

## Часы: «Учимся читать время»

Три режима переключаются вкладками:

1. **Выбери время** — на часах показывается время, нужно выбрать правильный вариант из четырёх. Три уровня сложности:
   - «Легко» — на циферблате подписаны минуты (5–60), время кратно 5;
   - «Средне» — подписей нет, время кратно 5, три сердечка;
   - «Сложно» — любая минута, два сердечка, варианты записаны только в 24-часовом виде.
2. **Запиши время** — время нужно ввести цифрами. Уровни те же, что в первом режиме. На «Сложно» ответ должен совпадать с точностью до минуты. Принимаются оба чтения: например, `13:45` и `01:45` — это одно и то же положение стрелок.
3. **Поставь время** — нужно выставить стрелки под объявленное время. Стрелки можно крутить кнопками или тянуть мышью/пальцем. На «Легко/Средне» минуты шагают по 5, на «Сложно» — по 1. На «Легко» цифровое табло показывает выставляемое время; на остальных уровнях оно скрыто, но проверка работает.

Особенности:

- время и его «двойник» через 12 часов считаются одним и тем же заданием, поэтому принимаются оба варианта;
- на «Средне» и «Сложно» есть сердечки: серия ошибок снимает балл, правильный ответ возвращает все сердечки;
- балл начисляется только за правильный ответ и никогда не уходит ниже нуля;
- после ответа результат и кнопка **Дальше** остаются на экране — следующее задание начинается только по нажатию;
- кнопка **Сброс** обнуляет счёт и выдаёт новое задание;
- кнопка **Помощь** открывает памятку с картинкой на весь экран; закрывается щелчком в любом месте или клавишей `Esc`.

## Счёт: «Учимся считать»

Страница `counter.html` — отдельная игра, не связанная с часами.

- Ребёнку показывается пример на сложение или вычитание с ответом от 0 до 10, например `7 + 2 = ?` или `9 − 4 = ?`.
- Ответ выбирается одной из четырёх крупных кнопок, правильный вариант всегда один.
- За правильный ответ начисляется балл; при ошибке подсвечивается верный вариант и показывается равенство целиком.
- Результат и кнопка **Дальше** остаются на экране до нажатия — без таймеров и автоперехода.
- Клавиши `1`–`4` выбирают вариант, `Enter` переходит к следующему примеру.
- **Сброс** обнуляет счёт.
- Один и тот же пример не выдаётся два раза подряд.

## Состав репозитория

```
index.html      разметка тренажёра часов
app.js          логика часов: циферблат, задания, проверка, счёт, режимы, помощь
styles.css      стили тренажёра часов
clock_help.png  картинка-памятка для кнопки «Помощь»
counter.html    самостоятельная игра «Учимся считать» (разметка, стили и скрипт внутри файла)
openspec/       спецификации тренажёра часов
```

`counter.html` намеренно не использует `app.js` и `styles.css`: это отдельный продукт, который можно менять, не задевая часы.

## Проверка изменений

Автоматических тестов нет. Любое изменение проверяется вручную в настоящем браузере: открыть страницу, пройти режимы, посмотреть консоль на ошибки. Для часов удобно проверить все три вкладки и все три уровня, а для счёта — верный и неверный ответ, «Дальше» и «Сброс».
