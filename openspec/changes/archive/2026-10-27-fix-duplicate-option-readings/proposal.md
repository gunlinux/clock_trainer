# Proposal

## Why

На уровнях 1–2 вторая строка варианта иногда повторяет первую: «12:15 / 12:15», «9:40 / 09:40». Для ребёнка это выглядит как дубль и не даёт 24-часового альтернативного чтения, хотя именно вторая строка должна знакомить с 24-часовым форматом.

## What Changes

- На уровнях 1–2 каждый вариант по-прежнему показывает две строки: крупную 12-часовую и мелкую 24-часовую, но вторая SHALL всегда отличаться по времени от первой.
- Если прямой 24-часовой записью оказалось бы то же самое время (часы 1–12), вторым чтением показывается двойник +12 часов: `9:40` → «9:40 / 21:40», `12:15` → «12:15 / 00:15».
- Для часов 0 и 13–23 ничего не меняется: там чтения уже различаются (`12:15 / 00:15`, `1:15 / 13:15`).
- Уровень 3 не затрагивается: его варианты остаются однострочными в 24-часовом формате.
- Сообщения после ответа не меняются — они уже перечисляют оба 24-часовых чтения.
- Внутренние значения вариантов, дедупликация по положению стрелок и проверка правильности не меняются: правка только в отображении.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `choice-mode-difficulty`: добавляется требование к двухстрочному формату вариантов на уровнях 1–2 — второе чтение всегда отличается от первого, при совпадении используется двойник +12 часов.

## Impact

- `app.js` — подготовка подписей варианта (`pairLabel`/`renderOptions`).
- `styles.css` — без изменений: размеры строк и классы `.t12`/`.t24` остаются прежними.
- `index.html`, режимы 2 и 3, счёт, штрафы и пауза не затрагиваются.
- Внешних зависимостей и сохранённых данных нет.
