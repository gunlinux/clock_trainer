# Spec Delta

## REMOVED Requirements

### Requirement: Пауза между ответами при вводе

**Reason**: Пауза перед ответом и обратный отсчёт убраны: после ответа сообщение остаётся на экране, а следующий раунд начинается только по кнопке «Дальше».

**Migration**: Правила ручного перехода между раундами описаны в спецификации `manual-round-advance`; новый раунд принимает ответ сразу, без ожидания.
